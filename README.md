# 🛒 বাজার দর (BazarDor)

**BazarDor** is a market price tracking web application that helps users check daily prices of essential products, compare prices across markets, and make smarter shopping decisions.

🌐 **Live Website:** https://bazar-check-lac.vercel.app/

📂 **GitHub Repository:** https://github.com/ridumondol/Bazar-Check

## ✨ Key Features

1. **Daily Market Prices** — Browse prices of essential products such as rice, lentils, oil, vegetables, fish, and meat.

2. **Category-Based Browsing** — Explore products easily through organized categories.

3. **Product Price Comparison** — Compare product prices across different markets to make informed purchasing decisions.

4. **User Authentication** — Sign up and sign in to access account-related features.

5. **Responsive Design** — Enjoy a user-friendly experience across desktop, tablet, and mobile devices.

## 🛠️ Technologies Used

- **Next.js** — React framework for building the web application.
- **React** — Component-based user interface development.
- **TypeScript** — Type-safe JavaScript development.
- **Tailwind CSS** — Responsive styling and UI design.
- **MongoDB** — Database integration.
- **Better Auth** — User authentication.

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/ridumondol/Bazar-Check.git
```

Navigate to the project directory:

```bash
cd Bazar-Check
```

Install dependencies:

```bash
npm install
```

Create a `.env.local` file and configure the required environment variables.

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
